# Workspace Custom Rules — CSC360

## Note-Taking & Reflection Instructions

Whenever instructed to write class notes or reflections, always follow this standard document format:

1. **File Naming & Organization**:
   - Save session documents in the `Notes/` directory named as `session_<DDMMYY>.md` (e.g., `session_060826.md`, `session_130826.md`, `session_180826.md`).

2. **Document Structure**:
   - **Section 1: 📝 Class Notes**:
     - Group content by topics (`### Topic 1: [Topic Title]`).
     - Write **1 to 2 detailed paragraphs per topic**.
     - Include visual diagrams (Mermaid flowcharts/diagrams or illustrations) wherever required to clarify algorithms, architectures, or workflows.
   - **Section 2: 💡 Class Reflection — DD/MM/YY**:
     - **Title with Date**.
     - **List of Topics Covered**.
     - **Reflections**: Exactly **1 to 2 lines per topic** summarizing key takeaways.
