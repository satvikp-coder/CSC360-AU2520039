# 📝 Class Notes

### Chapter 1: The Java SE 8 Stream Library
The Stream API shifts collection processing from explicit iteration to declarative pipelines. Core concepts include lazy evaluation, intermediate operations (filter, map, flatMap) and terminal operations (collect, reduce). Streams can be created from collections, arrays, or I/O sources and support primitive specializations (IntStream, LongStream, DoubleStream) as well as parallel execution for performance gains.

### Chapter 2: Input and Output
Java I/O is organized into byte‑oriented streams and character‑oriented readers/writers. The classic hierarchy (InputStream/OutputStream) is extended by buffering, data, and object streams. NIO introduced Channels, Buffers, and the Files API for more efficient file manipulation, memory‑mapped files, and regular‑expression based filtering.

### Chapter 3: XML Processing
XML handling in Java includes DOM (tree‑based), SAX (event‑driven), and StAX (pull‑parser). Validation uses DTDs or XSD schemas. XPath provides concise navigation, while XSLT enables transformation of XML documents. The javax.xml APIs also support namespace handling and streaming generation.

### Chapter 4: Networking
Networking revolves around `Socket` and `ServerSocket` for TCP, with `URLConnection`/`HttpURLConnection` for HTTP access. Java supports URL/URI manipulation, proxy configuration, and form posting. Higher‑level APIs such as `java.net.http` (Java 11+) simplify asynchronous requests. E‑mail can be sent via JavaMail.

### Chapter 5: Database Programming (JDBC)
JDBC abstracts relational database access. Drivers register via `DriverManager`, connections are obtained from URLs, and statements (Statement, PreparedStatement, CallableStatement) execute SQL. ResultSets provide row access, while transaction management relies on `setAutoCommit`, `commit`, and `rollback`. Batch updates and generated keys streamline bulk operations.

### Chapter 6: Date and Time API
The `java.time` package (JSR‑310) replaces the legacy `Date`/`Calendar`. `LocalDate`, `LocalTime`, `LocalDateTime`, and `ZonedDateTime` represent immutable date‑time objects. Adjusters, formatters (`DateTimeFormatter`), and parsers enable flexible handling, and interop with legacy `java.util.Date` is provided via `Instant`.

### Chapter 7: Internationalization
`Locale` encapsulates language and region. `NumberFormat`, `DateFormat`, and `MessageFormat` produce locale‑aware representations. Resource bundles (`PropertyResourceBundle`) store localized strings, while collation (`Collator`) handles sorting according to cultural rules.

### Chapter 8: Scripting, Compiling, and Annotation Processing
The Scripting API (`javax.script`) allows embedding languages like JavaScript. The Compiler API (`javax.tools`) enables in‑process compilation of source files. Annotations can be processed at compile‑time via `javax.annotation.processing`, generating source code or performing validation.

### Chapter 9: Security
Class loading occurs through a delegation model; custom loaders can isolate namespaces. The SecurityManager enforces permissions defined in policy files. JAAS provides pluggable authentication, while cryptographic services (MessageDigest, Signature, Cipher) support hashing, signing, and encryption.

### Chapter 10: Advanced Swing
Swing provides rich UI components. `JList`, `JTable`, and `JTree` rely on model‑view‑controller patterns. Custom renderers/editors enable bespoke cell appearance. Layout managers, split panes, tabbed panes, and internal frames facilitate complex windowing. Progress indicators (`JProgressBar`) and drag‑and‑drop APIs enhance user interaction.

### Chapter 11: Advanced AWT
The AWT rendering pipeline handles shapes, strokes, paints, and transformations. `BufferedImage` and related I/O classes manage image data. Printing APIs (`PrinterJob`, `Pageable`) support document rendering, while the clipboard system offers data transfer via `Transferable` and `DataFlavor`.

### Chapter 12: Native Methods (JNI)
JNI bridges Java with native C/C++ code. Method signatures are encoded, and native libraries are loaded via `System.loadLibrary`. Primitive and object data can be exchanged, with careful management of references and error handling. An example is accessing the Windows Registry from Java.
