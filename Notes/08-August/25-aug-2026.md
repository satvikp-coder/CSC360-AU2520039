# 📝 Class Notes

### Topic 1: Importance of `pom.xml` in Maven Projects / Java
The `pom.xml` (Project Object Model) file is the core descriptor for a Maven project. It declares the project's coordinates (groupId, artifactId, version), its dependencies, plugins, build profiles, and the directory structure. Maven uses this single source of truth to resolve transitive dependencies, manage the build lifecycle, and produce reproducible builds across environments. Without a correctly configured `pom.xml`, Maven cannot compile, test, or package the application, making it indispensable for modern Java development.

### Topic 2: `javax.swing` in JavaFX
While JavaFX is the newer UI toolkit, many legacy components from `javax.swing` are still relevant. Swing provides a mature set of widgets (e.g., JTable, JTree) and can be embedded inside a JavaFX scene via `SwingNode`. Understanding how Swing interoperates with JavaFX helps when migrating older applications or when a specific Swing component offers functionality not yet replicated in JavaFX.

### Topic 3: Threads vs Processes
A **process** is an independent execution unit with its own memory space, created by the operating system. A **thread** is a lightweight execution path within a process that shares the same memory, allowing quicker context switches and communication. Threads are ideal for fine‑grained parallelism (e.g., UI responsiveness), whereas processes are used for isolation, security, or when separate resources are required.

### Topic 4: Importance of Threads in Programs
Threads enable concurrent execution, preventing UI blocking and improving throughput on multi‑core CPUs. By delegating long‑running tasks (I/O, calculations) to background threads, the main thread can keep the user interface responsive. Proper thread management also reduces latency and makes better use of system resources.

### Topic 5: Thread Safety
Thread safety ensures that shared mutable state is accessed in a way that avoids race conditions and data corruption. Techniques include synchronized blocks, `Lock` objects, immutable data structures, and thread‑local storage. Designing APIs to be inherently thread‑safe (e.g., using concurrent collections) simplifies multi‑threaded programming.

### Topic 6: "Click Me" Button Program in JavaFX
The classic “Click Me” example demonstrates how to create a JavaFX `Button`, attach an `EventHandler`, and update UI state (e.g., change a label) when the button is pressed. It showcases the JavaFX application lifecycle (`start` method), scene graph construction, and the necessity of running UI updates on the JavaFX Application Thread.
