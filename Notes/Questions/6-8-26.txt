Q1. How is computer graphics different from image processing?

Computer Graphics is used to create new images, animations, or visual objects using a computer. It focuses on generating graphics.

Image Processing is used to improve, edit, or analyze existing images. It works on images that are already available.

Example:

Computer Graphics: Creating a game character or 3D model.
Image Processing: Removing noise from a photo or increasing image quality.
Q2. What are the geometry primitives of drawing?

Geometry primitives are the basic shapes used to create graphics.

They include:

Point
Line
Circle
Rectangle
Triangle
Polygon
Curve

These simple shapes are combined to create complex drawings.

Q3. Describe graphical framework in Java.

Java provides different frameworks for creating graphical user interfaces (GUI).

AWT (Abstract Window Toolkit)
The oldest Java GUI framework.
Uses the operating system's native components.
Lightweight features are limited.
Swing
Built on top of AWT.
Provides more components like buttons, tables, menus, etc.
Platform-independent and more flexible.
JavaFX
A modern GUI framework.
Supports animations, multimedia, CSS styling, and rich user interfaces.
Used for developing modern desktop applications.
Runtime
The Java Runtime Environment (JRE) executes Java programs and provides the required libraries for GUI applications.
Q4. What is the design pattern for creating user interfaces?

Java uses the Event Listener Model.

The user performs an action (click, type, move the mouse).
An event is generated.
A listener detects the event.
The program executes the required action.

This model helps make applications interactive.

Q5. How is static graphics different from interactive graphics?
Static Graphics
Do not change after they are displayed.
No user interaction.
Example: A logo or an image.
Interactive Graphics
Respond to user actions.
Can change based on mouse or keyboard input.
Example: Games, drawing software, or simulations.
Q6. How is curve connected to calculus?

A curve is closely related to calculus because calculus studies smooth and continuous changes.

Curves are represented using mathematical functions.
Calculus helps find the slope, length, area, and curvature of a curve.
Smooth continuous curves are important in computer graphics and animation.
Q7. Describe SSH and HTML accessing GitHub repository.
SSH

SSH (Secure Shell) is a secure method of connecting to GitHub.

Uses public and private keys.
Allows secure authentication without entering a password every time.
Commonly used by developers.
HTTPS (not HTML)

HTTPS is another way to access a GitHub repository.

Uses username/password or Personal Access Token.
Easier for beginners.
Does not require SSH key setup.
Q9. Mention tools used for SSH.

The main SSH tool is:

ssh-keygen

Purpose:

Generates a public key and a private key.
Used to authenticate securely with GitHub servers.

Common command:

ssh-keygen
Q10. What are public and private keys?

When ssh-keygen is executed, two keys are created.

Public Key
Stored in the .pub file.
Shared with GitHub.
Used to identify the user.
Private Key
Stored without the .pub extension.
Must be kept secret.
Used by the computer to prove your identity.

Both keys work together for secure authentication.
