Maven & Java 2D Square Program

Maven Overview
- Maven is a build automation and project management tool for Java applications.
- Manages project structure, dependencies, compilation, and execution automatically.
- Uses `pom.xml` (Project Object Model) as the central configuration file.

Key Maven Commands
- `mvn clean`: Cleans previous build outputs (`target/` directory).
- `mvn compile`: Compiles Java source files into bytecode under `target/classes`.
- `mvn test`: Runs unit test cases (e.g., JUnit tests in `AppTest.java`).
- `mvn exec:java -Dexec.mainClass="com.example.App"`: Runs the main Java application.

Java 2D Square Program (`nvm-square`)
- Created a Java Swing program using Maven directory layout (`src/main/java/com/example/App.java`).
- `App` class extends `javax.swing.JPanel`.
- Overrides `paintComponent(Graphics g)` to perform 2D shape rendering.
- Uses `g.setColor(Color.BLUE)` to set the drawing brush color.
- Uses `g.fillRect(150, 100, 200, 200)` to render a solid blue square.
- Hosted inside a `JFrame` window (size 500x500) set to `EXIT_ON_CLOSE`.

Summary
- Learned how Maven simplifies building Java Swing applications.
- Practiced custom 2D shape drawing using Java AWT Graphics primitives.
