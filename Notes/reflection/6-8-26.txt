SSH vs HTTPS in GitHub

GitHub repositories can be accessed using SSH or HTTPS.

SSH
Secure connection using key authentication.
Uses ssh-keygen to generate keys.
Public key is stored in the .pub file.
Private key is stored in the file without the .pub extension.
No password is needed after setup.
HTTPS
Connects using a web-based secure protocol.
Uses a username and Personal Access Token.
Easier for beginners to set up.
Vector Graphics vs Raster Graphics
Vector Graphics
Made using mathematical formulas.
Can be resized without losing quality.
Examples: Logos, icons, illustrations.
Raster Graphics
Made of pixels arranged in a matrix.
Quality decreases when enlarged.
Examples: JPEG, PNG, photographs.
