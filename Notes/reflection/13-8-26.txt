3. Java GUI & Graphics Frameworks Comparison
--------------------------------------------
- AWT (Abstract Window Toolkit):
  * Original Java GUI toolkit (`java.awt`).
  * Heavyweight components mapping directly to native OS peers.
- Swing:
  * Built on AWT (`javax.swing`).
  * Lightweight, 100% Java components painted on canvas (`JPanel`, `JFrame`).
- JavaFX:
  * Modern Java client platform supporting hardware-accelerated 2D/3D graphics, FXML, and CSS.

5. Computer Graphics vs Image Processing
-----------------------------------------
- Computer Graphics: Synthesizes new visual objects and scenes from mathematical models (e.g., 3D gaming, vector shapes).
- Image Processing: Analyzes and enhances existing raster images (e.g., photo filtering, noise reduction).
- Geometric Primitives: Basic shapes used in rendering (Point, Line, Triangle, Rectangle, Circle, Polygon, Curve).
