## 1. Maven Project Initialization (`maven-square`)

* **Core File**: `pom.xml` (Project Object Model) managing dependencies, plugins, and JDK compiler target versions.
* **Key Commands**:

  ```bash
  # Execute main application
  mvn exec:java -Dexec.mainClass="com.example.App"
  ```

## 2. Java 2D Transformations (`moving-triangle`)

### Moving Triangle (`MovingTriangle.java`)
* Defines an equilateral-ish triangle centered at origin `(0, 0)`.
* Implements `MouseMotionListener` to track cursor coordinates `(mouseX, mouseY)`.
* Applies `AffineTransform.translate(mouseX, mouseY)` dynamically inside `paintComponent()` to align the triangle's centroid with the mouse cursor.

### Zooming Triangle (`ZoomingTriangle.java`)
* Implements continuous zoom-in / zoom-out animation driven by a 30ms Swing `Timer`.
* Oscillates scale factor between `MIN_SCALE` (0.4) and `MAX_SCALE` (2.5).
* Combines `AffineTransform.translate(cx, cy)` followed by `AffineTransform.scale(scale, scale)` so scaling occurs about the panel's center rather than the top-left origin.

## 3. Java GUI & Graphics Framework Comparison

| Framework | Component Type | Architecture & Characteristics |
| :--- | :--- | :--- |
| **AWT** (`java.awt`) | Heavyweight | Original Java toolkit. Wraps native OS platform peers. Primitive drawing via `Graphics`. |
| **Swing** (`javax.swing`) | Lightweight | Built on AWT. 100% pure Java components painted directly onto canvas (`JPanel`, `JFrame`). |
| **JavaFX** | Modern Platform | Modern replacement for Swing. Hardware-accelerated 2D/3D graphics, FXML UI, and CSS styling. |

## 4. GitHub SSH & Key Security

* **`ssh-keygen`**: Command-line tool used to generate cryptographic RSA or Ed25519 key pairs.
* **Public Key** (`id_ed25519.pub`): Shared with GitHub server for user identification.
* **Private Key** (`id_ed25519`): Remains strictly secret on the local host to authenticate pushes/pulls without password prompts.

## 5. Computer Graphics vs. Image Processing

* **Computer Graphics**: Generates new synthetic visual content from mathematical models (e.g., 3D rendering, vector UI).
* **Image Processing**: Analyzes, enhances, or transforms pre-existing raster images (e.g., noise reduction, edge detection).
* **Primitive Shapes**: Basic geometric primitives used in rendering (Points, Lines, Triangles, Rectangles, Circles, Polygons, Curves).
