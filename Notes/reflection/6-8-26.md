## 1. GitHub Authentication: SSH vs HTTPS

| Feature | SSH (Secure Shell) | HTTPS (Hypertext Transfer Protocol Secure) |
| :--- | :--- | :--- |
| **Authentication** | Public & Private Key Pairs (`ssh-keygen`) | Username + Personal Access Token (PAT) |
| **Setup Effort** | Requires one-time key generation and upload | Immediate, web credential-based |
| **Pushes / Pulls** | Passwordless after initial configuration | Requires token storage / credential manager |
| **Key Components** | • **Public Key** (`.pub` file): Uploaded to GitHub<br>• **Private Key** (no extension): Kept secret on machine | Web token configured in Git credential helper |

## 2. Graphics Fundamentals: Vector vs Raster

### Vector Graphics
* **Definition**: Graphics generated mathematically using points, lines, curves, and shapes.
* **Scalability**: Infinitely scalable without any loss of quality or pixelation.
* **Common Use Cases**: Logos, typography, vector illustrations, CAD models.

### Raster Graphics
* **Definition**: Bitmapped images rendered via a fixed grid of pixels.
* **Scalability**: Quality degrades when scaled up (becomes pixelated/blurry).
* **Common Use Cases**: Digital photographs, complex textures, JPEG/PNG images.
