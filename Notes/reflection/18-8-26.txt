Topic: Java Graphics Frameworks & Maven Square Implementation

1. Three Main Java GUI & Graphics Frameworks
--------------------------------------------
- AWT (Abstract Window Toolkit):
  * The original Java GUI framework (`java.awt`).
  * Uses native operating system windowing components ("heavyweight" components).
  * Provides core 2D graphics primitives (`Graphics`, `Color`, `Font`, `Shape`).

- Swing:
  * Built on top of AWT (`javax.swing`).
  * Provides 100% pure Java components ("lightweight" components) painted directly onto canvas surfaces (`JPanel`, `JFrame`).
  * Supports flexible Look-and-Feel customization and custom double-buffered rendering.

- JavaFX:
  * Modern Java client platform designed to replace Swing.
  * Supports hardware-accelerated 2D and 3D graphics, CSS styling, FXML UI layouts, and media integration.


2. Detailed Algorithm of the Maven Square Program (`App.java`)
--------------------------------------------------------------
Step 1: Application Initialization
  - Instantiates a `JFrame` window titled "My Maven Square Project" and sets window dimensions to 500x500 pixels.
  - Sets window closing operation to `EXIT_ON_CLOSE` to terminate the JVM process when closed.

Step 2: Component Registration
  - Instantiates the `App` custom panel (extending `JPanel`) and mounts it inside the `JFrame`.
  - Sets window visibility to true (`setVisible(true)`), triggering the Swing Event Dispatch Thread (EDT).

Step 3: Graphics Context Preparation
  - Swing automatically invokes `paintComponent(Graphics g)` on the EDT.
  - Calls `super.paintComponent(g)` to clear the panel background canvas and initialize graphics buffer state.

Step 4: Color & Shape Rasterization
  - Calls `g.setColor(Color.BLUE)` to set the current drawing brush color state to Blue.
  - Executes `g.fillRect(x=150, y=100, width=200, height=200)`:
    * Positions the top-left vertex at coordinate (150, 100).
    * Fills a rectangular pixel matrix spanning 200 pixels wide by 200 pixels high, rendering a solid blue square.


3. Standard Folder Structure of `maven-square`
----------------------------------------------
```text
maven-square/
├── pom.xml                                   # Central Maven configuration & dependencies
└── src/
    ├── main/
    │   └── java/
    │       └── com/
    │           └── example/
    │               └── App.java              # Main Java Swing application source code
    └── test/
        └── java/
            └── com/
                └── example/
                    └── AppTest.java          # Unit test source code (JUnit)
```

Folder Descriptions:
- `pom.xml`: Project Object Model defining project metadata, compiler version, and dependencies.
- `src/main/java/`: Contains production Java application source files organized by package (`com.example`).
- `src/test/java/`: Contains automated test cases and assertions (`AppTest.java`).
- `target/` (generated build folder): Holds compiled bytecodes (`.class` files) and packaged JAR artifacts.
